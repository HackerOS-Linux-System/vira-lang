v0.1 · hyperc + vira

Pisz w Hyper. Uruchamiaj wszędzie, gdzie działa JavaScript.

Statyczne typowanie, struct/enum/trait, wyczerpujące dopasowanie wzorców - i natywny dostęp do całego ekosystemu npm/JSR bez pisania jednej linijki wrappera. hyperc transpiluje, vira instaluje, buduje i uruchamia.

Zacznij w 2 minuty Zobacz źródło Poznaj vira
shapes.hyperhyper
enum Shape {
    Circle(radius: f64),
    Rectangle(width: f64, height: f64),
}

fn area(shape: Shape) -> f64 {
    return match shape {
        Circle(r) => 3.14159 * r * r,
        Rectangle(w, h) => w * h,
    }
}
shapes.jshyperc wyjście
// wygenerowane przez hyperc
class Shape {
  constructor(tag, values) {
    this.tag = tag;
    Object.assign(this, values);
  }
  static Circle(radius) {
    return new Shape("Circle", { radius });
  }
  static Rectangle(width, height) {
    return new Shape("Rectangle", { width, height });
  }
}
function area(shape) {
  return (() => {
    const __subject = shape;
    if (__subject.tag === "Circle") {
      const { radius: r } = __subject;
      return 3.14159 * r * r;
    } else if (__subject.tag === "Rectangle") {
      const { width: w, height: h } = __subject;
      return w * h;
    }
    throw new Error("...");
  })();
}
Dlaczego Hyper

Rozwiązuje jeden konkretny ból TypeScriptu

Nie nowa składnia dla samej nowości - natywna obsługa bibliotek JS/TS bez pisania ani utrzymywania osobnych plików .d.ts.

Import wprost z npm

Żadnej warstwy pośredniej. import trafia 1:1 do wygenerowanego ESM.

import { readFileSync } from "fs"
import path from "path"

let p = path.join("a", "b")

ADT + wyczerpujący match

enum z danymi i match jako obywatele pierwszej klasy, nie switch na atrapie unii.

enum Result<T, E> {
    Ok(value: T),
    Err(error: E),
}

self, nie this

Kompilator statycznie wie, gdzie jest self - koniec z bugami bindingu this w callbackach.

impl Point {
    fn length(self) -> f64 {
        return sqrt(self.x)
    }
}
Język

Statyczny checker, nie tylko erasure typów

hyperc śledzi typy przez przypisania i łańcuchy wywołań metod, egzekwuje pub na granicy modułów i sprawdza zgodność traitów przed wygenerowaniem jednej linijki JS.

Moduły i widoczność

// geometry.hyper
pub struct Rectangle { width: f64, height: f64 }

fn internalHelper() -> string { ... } // prywatne

// main.hyper
import { Rectangle } from "./geometry.hyper"
